# LUMEN ENT. 브랜드 영상 제작 프로젝트

## 1. 프로젝트 소개

**LUMEN ENT.**는 K-POP을 사랑하는 글로벌 10~30대를 대상으로 한 엔터테인먼트 브랜드 영상 프로젝트입니다.

한 사람의 작은 꿈이 끊임없는 노력과 성장을 통해 세계를 감동시키는 무대로 이어지는 과정을 영상으로 표현했습니다.

> **"모든 꿈은, 빛나는 한 장면이 된다."**
> **"Every dream, becomes a shining scene."**

# 3. 영상 제작 콘셉트

## 영상 제목

**LUMEN ENT.**

## 영상 메시지

작은 연습실에서 시작된 한 사람의 꿈이
끊임없는 노력과 성장을 통해
마침내 세계의 무대 위에서 빛나는 순간으로 완성되는 스토리입니다.

## 영상 구성

| Scene   | 내용               | 전달 메시지                |
| ------- | ---------------- | --------------------- |
| Scene 1 | The Beginning    | 모든 꿈은 작은 시작에서 출발한다    |
| Scene 2 | Growth           | 성장은 포기하지 않는 순간들로 완성된다 |
| Scene 3 | Dream Comes True | 꿈은 결국 무대 위에서 빛난다      |
| Scene 4 | Ending           | 모든 꿈은, 빛나는 한 장면이 된다   |

---

# 4. Scene 구성 및 제작 과정

## Scene 1. The Beginning (2초)

### 목표 메시지

> 모든 꿈은 작은 시작에서 출발한다.

### 화면 구성

* 텅 빈 연습실
* 거울 앞에서 혼자 춤을 연습하는 연습생
* 움직임을 비추는 조명
* 영화 같은 분위기의 연출

### 내레이션 및 자막

"모든 꿈은 작은 시작에서 출발한다."

### 사용 도구

* **OpenAI Sora 2**

  * AI 영상 생성

### 입력 프롬프트

```
롱샷. 텅 빈 연습실.
거울 앞에서 혼자 춤을 연습하는 연습생.
영화 같은 분위기와 조명 연출.
```

---

# Scene 2. Growth (3초)

### 목표 메시지

> 성장은 포기하지 않는 순간들로 완성된다.

### 화면 구성

* 연습생 얼굴 클로즈업
* 흐르는 땀방울 표현
* 넘어졌다가 다시 일어나는 모습
* 무대 조명이 켜지며 미래를 암시

### 사용 도구

* **OpenAI Sora 2**

  * AI 영상 생성

### 입력 프롬프트

```
클로즈업.
땀방울이 흐르는 연습생의 얼굴.
연습생이 넘어졌다가 다시 일어나 춤을 이어간다.
동시에 무대 조명이 켜지며 미래를 암시한다.
```

---

# Scene 3. Dream Comes True (3초)

### 목표 메시지

> 꿈은 결국 무대 위에서 빛난다.

### 화면 구성

* 화려한 공연 무대
* 공연 중인 가수
* 객석의 수많은 팬들
* 형형색색 네온 응원봉
* 웅장한 콘서트 조명 연출

### 사용 도구

* **OpenAI Sora 2**

  * AI 영상 생성
* **CapCut**

  * 환호성 효과음 삽입

### 입력 프롬프트

```
화려한 네온색 응원봉들 사이에서
열정적으로 무대 위에서 공연하는 가수.
행복한 표정으로 웃고 있으며,
웅장한 콘서트 분위기와 조명 연출.
```

---

# Scene 4. Ending (2초)

### 목표 메시지

> 모든 꿈은, 빛나는 한 장면이 된다.

### 화면 구성

* 꿈을 이룬 가수의 얼굴 클로즈업
* 행복과 감동이 담긴 표정
* 서서히 암전
* 브랜드 로고 및 메시지 노출

### 사용 도구

* **OpenAI Sora 2**

  * AI 영상 생성
* **CapCut**

  * 브랜드 메시지 텍스트 삽입
  * 브랜드 로고 이미지 삽입

### 입력 프롬프트

```
웃는 가수의 얼굴을 클로즈업한다.
꿈을 이룬 순간의 행복하고 벅찬 감정을 표현한다.
이후 화면이 서서히 암전된다.
```

# 5. Prompt 수정 사례

## Scene 4 프롬프트 개선 과정

### 수정 전 의도

목표 메시지를 영상 안에 담아내어 의미 전달

### 문제점

* 피사체 표현이 불명확함
* 감정 전달 부족
* 부자연스러운 이미지 생성

### 수정 후 변경 사항

기존 프롬프트:

```
웃는 가수의 얼굴을 클로즈업한 뒤 서서히 암전되는 화면
```

수정 프롬프트:

```
꿈을 이룬 가수의 행복한 모습과 벅찬 감정을 표현하기 위해
웃는 가수의 얼굴을 클로즈업한 뒤 서서히 암전되는 화면.
```

### 결과 변화

* 인물 표현의 디테일 향상
* 감정 표현 강화
* 브랜드 메시지 전달력 증가

# 8. Project Outcome

LUMEN ENT. 브랜드 영상은
AI 영상 생성 기술을 활용하여 **꿈 → 노력 → 성장 → 성공**이라는 브랜드 스토리를 시각적으로 표현했습니다.

작은 시작이 결국 세계를 감동시키는 무대가 된다는 메시지를 통해
글로벌 K-POP 팬들에게 희망과 영감을 전달하는 것을 목표로 합니다.
